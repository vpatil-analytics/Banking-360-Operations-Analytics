🏦 Banking 360 Operations Analytics

📌 Project Overview

Banking 360 Operations Analytics is an end-to-end Business Intelligence project designed to analyze banking operations across customers, accounts, transactions, cards, loans, loan payments, branches, complaints, and service requests.

The project uses SQL and Power BI to transform banking operational data into meaningful business insights and interactive dashboards.

🎯 Business Objectives

- Analyze customer and account activity
- Monitor transaction volume and transaction value
- Analyze card and account performance
- Understand loan portfolio performance
- Track loan repayment and outstanding amounts
- Analyze branch performance
- Monitor customer complaints
- Analyze service requests
- Identify high-value customers
- Support data-driven business decisions

🗂️ Data Model

The project contains 10 tables:

Table| Description
Customers| Customer information
Accounts| Customer account information
Transactions| Banking transaction activity
Cards| Customer card information
Loans| Loan portfolio information
Loan_Payments| Loan repayment activity
Service_Requests| Customer service requests
Complaints| Customer complaints
Branches| Banking branch information
Date| Date dimension for time analysis

🔍 Analysis Areas

👥 Customer Analysis

Customer activity, customer status, transaction behavior, and high-value customers.

💳 Account & Card Analysis

Account types, account status, card portfolio, and customer account activity.

💰 Transaction Analysis

Transaction volume, transaction value, transaction types, monthly trends, and top customers.

🏦 Loan Analysis

Loan portfolio, loan types, loan amounts, payments, and outstanding balances.

🏢 Branch Analysis

Branch-level customer, account, transaction, and loan activity.

📞 Customer Service Analysis

Complaints and service requests by category and status.
